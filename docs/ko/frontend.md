## 라우팅 구조

Next.js App Router를 활용한 아티스트 기반 동적 라우팅. 각 아티스트는 고유 색상이 동적으로 적용된 브랜디드 랜딩 페이지를 보유합니다. 라우트는 랜딩 페이지, 퀴즈 플로우, 결과 표시를 포함합니다.

`/shinee`, `/fx`처럼 아티스트별 세그먼트 구조를 따르므로, 새 아티스트 추가는 플로우 코드 재작성 없이 아티스트 단위의 데이터·매핑·테마 교체만으로 가능합니다.

---

## 결과 경험

결과 페이지는 매칭된 곡과 함께 같은 응답에 번들링된 가까운 곡 추천을 함께 노출합니다. 한 곡으로 좁혀지지 않는 경우(no-match·질문 소진)에도 동일한 컴포넌트로 가까운 곡을 보여주어 사용자가 막다른 길에 닿지 않도록 합니다.

---

## 배포

[OpenNext](https://opennext.js.org/) 어댑터를 통한 **Cloudflare Workers** 배포

- 개발 및 프로덕션 워커 분리
- CORS 이슈 방지를 위해 프론트엔드 라우트를 통한 백엔드 API 프록시

---

## 테스트 & 품질

Jest + React Testing Library 기반의 단위 테스트로 hooks, 컴포넌트, API 클라이언트를 검증합니다. 수동 검증은 전체 퀴즈 플로우, 접근성, 크로스 브라우저 동작을 대상으로 합니다.

- 라우트별 메타데이터, `robots.ts`, `sitemap.ts`, 웹 매니페스트 운영
- Organization·WebApplication에 대한 JSON-LD structured data

---

## 주요 기능

- **공유하기**: 결과 확인 후 링크 복사 또는 X/Twitter 공유. 세션 만료 후에도 영속적 fallback 메커니즘을 통해 결과 접근 가능
- **성능**: Core Web Vitals를 위한 INP 및 CLS 최적화
- **보안**: API 시크릿을 서버 사이드(Cloudflare Worker 환경)에 보관, 모든 사용자 입력에 대한 유효성 검사, 엄격한 CSP / HSTS / Permissions-Policy 응답 헤더 적용
