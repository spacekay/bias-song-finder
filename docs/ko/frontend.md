# 프론트엔드 기술 스택

## 핵심 프레임워크

| 기술 | 비고 |
|-----------|------|
| Next.js | App Router |
| React | 19 |
| TypeScript | — |

---

## UI & 스타일링

| 기술 | 역할 |
|-----------|------|
| Tailwind CSS v4 | 유틸리티 퍼스트 스타일링 |
| shadcn/ui | 접근성을 고려한 컴포넌트 프리미티브 |
| Framer Motion | 애니메이션 및 트랜지션 |

---

## 상태 관리

**Zustand** — localStorage 영속성을 갖춘 경량 상태 관리. 같은 세션 내에서 페이지 새로고침 후에도 상태가 유지됩니다.

---

## 다국어 지원

한국어와 영어를 지원하는 커스텀 i18n 구현

- 아티스트 및 로케일별 번역 파일 구성
- 앱 내 언어 전환 토글 제공
- 모든 질문 텍스트, 선택지 라벨, UI 문구 완전 번역

---

## 라우팅 구조

Next.js App Router를 활용한 아티스트 기반 동적 라우팅. 각 아티스트는 고유 색상이 동적으로 적용된 브랜디드 랜딩 페이지를 보유합니다. 라우트는 랜딩 페이지, 퀴즈 플로우, 결과 표시를 포함합니다.

---

## 배포

[OpenNext](https://opennext.js.org/) 어댑터를 통한 **Cloudflare Workers** 배포

- 개발 및 프로덕션 워커 분리
- CORS 이슈 방지를 위해 프론트엔드 라우트를 통한 백엔드 API 프록시

---

## 주요 기능

- **공유하기**: 결과 확인 후 링크 복사 또는 X/Twitter 공유. 세션 만료 후에도 영속적 fallback 메커니즘을 통해 결과 접근 가능
- **성능**: Core Web Vitals를 위한 INP 및 CLS 최적화
- **보안**: API 시크릿을 서버 사이드(Cloudflare Worker 환경)에 보관, 모든 사용자 입력에 대한 유효성 검사
